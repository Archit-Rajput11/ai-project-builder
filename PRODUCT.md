# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
CS & IT engineering students, final-year capstone project teams, and academic project candidates who need complete, production-grade project scaffolding and structured thesis preparation.

## Product Purpose
Empower engineering students to architect, scaffold, and defend ambitious, production-ready capstone projects. Success means moving from an empty repository to a validated system architecture, 6-week Kanban roadmap, master AI copilot prompts for development, viva defense question banks, and IEEE-format thesis outlines.

## Positioning
Unlike generic code boilerplates or open-ended AI chatbots, AI College Project Builder provides holistic academic project scaffolding tailored to student skill levels and project complexity, with structured deliverables ready for faculty review and viva defense examinations.

## Operating Context
- High-density web developer console used primarily on desktop and laptop development environments, with responsive support for mobile reviews.
- Academic semester project cycles (typically 4–8 weeks), committee review milestones, and oral defense preparations.
- Development workflows integrating modern tech stacks (React, Next.js, Node.js, Python, PostgreSQL, Cloud deployments) alongside AI coding assistants (Cursor, Claude, v0).

## Capabilities and Constraints
- Automated AI Blueprint Generator powered by Google Gemini (system architecture, tech stack selection, file tree structure, 6-week roadmap, weekly AI copilot prompts, viva Q&A bank, and IEEE reports).
- Supabase Authentication (Email/Password & GitHub OAuth with PKCE session exchange).
- Account-bound Freemium quota: 1 free blueprint per authenticated Supabase account; Pro tier unlocks unlimited generations, custom project keywords, and an AI academic tutor.
- Interactive Kanban board milestone tracker and client-side PDF blueprint export.
- Server-side PostgreSQL quota enforcement with concurrency locking.

## Brand Commitments
- High-density dark console UI inspired by top developer platforms (Raycast, Supabase, Linear).
- Primary visual theme: Obsidian slate (`#080b11`, `#0c1017`) accented with matte indigo, violet, and electric blue highlights.
- Voice: Rigorous, encouraging, engineering-minded, and academically credible without feeling like a beginner tutorial.

## Evidence on Hand
- Next.js 16 (App Router) + React 19 + Tailwind CSS + Lucide Icons.
- Live Supabase database with `users`, `projects`, and `user_usage` schema.
- Integrated Gemini 2.5 generative engine.

## Product Principles
1. **Academic Credibility**: Blueprints, system architectures, and thesis outlines must withstand rigorous scrutiny from engineering faculty committees.
2. **Actionable Implementation**: Provide copy-pasteable AI copilot prompts and concrete repository file structures rather than abstract suggestions.
3. **High-Density Focus**: Emphasize scanability, clean typography hierarchy, and purposeful developer controls over decorative distractions.
4. **Resilient Integrity**: Guarantee that quotas, authentication, and project blueprints are securely bound to the user's account and persistent across devices.
